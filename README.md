# HFO - Human Function Optimization

Android application for HFO training.

## Features

- **Neural Decoupling**: Establish independent PC muscle control
- **Path Awakening**: S > PC wave contraction training
- **Peak Coupling**: Breath-hold pumping and chest nerve coupling training

## Requirements

- Android SDK 24+
- Gradle 8.7+

## Build

```bash
./gradlew assembleDebug
```

## Install

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

## Version

1.6.0
